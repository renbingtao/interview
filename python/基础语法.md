# Python 基础语法

## 标识符

1. 只能包含大小写英文、数字、下划线
2. 不能以数字开头
3. 区分大小写
4. 变量名不能设置为py内置的函数，如print

python官方推荐的写法：user_name

常量的写法和java一样，即USER_NAME

## 保留关键字

Python 的标准库提供了一个 keyword 模块，可以输出当前版本的所有关键字：

import keyword
print(keyword.kwlist)

## 缩进

python中定义了一个方法，**必须**用缩进来区分代码层级。在java中，则是用{}

## 多行语句

通常是一行写完一条语句，但如果语句很长，我们可以使用反斜杠 \ 来实现多行语句，例如：

item_one = 1
item_two = 2
item_three = 3
total = item_one + \
item_two + \
item_three
print(total) # 输出为 6

## 数字类型

有四种，如下

- int：如1，长整形。没有python2的Long
- bool：如True
- float：如1.23
- complex：复数，由实部和虚部组成，形式为a+bj，其中a是实部，b是虚部，j为虚数单位。如1.1+2.2j

## 字符串

Python 中单引号 ' 和双引号 " 使用完全相同

使用三引号(''' 或 """)可以指定一个多行字符串

```python
paragraph = """这是一个段落，
可以由多行组成"""
```

转义符 `\`

使用 r 可以让反斜杠不发生转义，如 r"this is a line with \n" 则 \n 会显示，并不是换行。r指raw

按字面意义级联字符串，如 "this " "is " "string" 会被自动转换为 this is string

字符串可以用 + 运算符连接在一起，用 * 运算符重复。如：

```python
a = '123'
print(a * 3)               # 输出123123123

print(a + '你好')         # 输出123你好
```

Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。左闭右开

```python
str = '123456789'
print(str[0:4])            # 输出1234
```

字符串的切片可以加上步长参数 step，语法格式如下：str[start:end:step]。如

str = '123456789'
print(str[0:5:2])           # 输出135

## 用户输入

input_str = input("请输入...")     # 等待用户输入，按回车结束输入

print(input_str)

## print 输出

print 默认输出是换行的，如果要实现不换行需要在变量末尾加上 end=""：

a = '123'
b = '456'
print(a, end=' ')
print(b, end=' ')   # 输出123 456 

## import 与 from...import

在 python 用 import 或者 from...import 来导入相应的模块。

将整个模块(somemodule)导入，格式为： import somemodule

从某个模块中导入某个函数,格式为： from somemodule import somefunction

从某个模块中导入多个函数,格式为： from somemodule import firstfunc, secondfunc, thirdfunc

将某个模块中的全部函数导入，格式为： from somemodule import *
