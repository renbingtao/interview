# 类

Python 的类是**创建对象的模板**，核心底层：**类本身也是对象（type 的实例）**。

> 一句话区分：
>
> - `class A:` → A 是类对象
> - `a = A()` → a 是实例对象

## 一、基础结构

```python
class Student:
    # 【类属性】：属于类，所有实例共享
    school = "珠海一中"

    # 构造初始化方法：实例初始化
    def __init__(self, name: str, age: int):
        # 【实例属性】self.xxx，绑定到单个实例
        self.name = name
        self.age = age

    # 【实例方法】第一个参数必须 self，代表当前实例
    def say(self):
        print(f"我是{self.name}，{self.age}岁")

# 创建实例
s1 = Student("张三", 16)
s2 = Student("李四", 17)
s1.say()
```

### 三个成员分类（重中之重）

1. **实例属性（self.xxx）**
   存在每个独立实例，实例之间互不干扰。
   `s1.name` 和 `s2.name` 互不影响。
2. **类属性（写在方法外面）**
   挂在类 `Student` 上，所有实例共享。

> ⚠️ 坑：如果 `s1.school = "二中"`，**不会修改类属性**，而是在 s1 实例上新建一个同名属性，遮蔽类属性。

```python
Student.school = "二中"  # 才是修改类属性，全部实例生效
```

3. 三种方法：实例方法、类方法、静态方法

```python
class Demo:
    # 实例方法：默认参数 self，访问实例属性
    def inst_func(self):
        print(self)

    # 类方法：@classmethod，第一个参数 cls 代表类本身
    @classmethod
    def cls_func(cls):
        print(cls)

    # 静态方法：@staticmethod，无默认参数，和类、实例无关
    @staticmethod
    def static_func():
        print("static")
```

调用方式：

```python
d = Demo()
d.inst_func()
Demo.cls_func()
Demo.static_func()
```

- 实例方法：需要实例，用来操作实例数据（最常用）
- 类方法：工厂方法、修改类属性、多构造函数场景
- 静态方法：工具函数，只是逻辑上归属这个类，不访问类 / 实例数据

> 工厂方法示例（类方法经典用法）

```python
class User:
    def __init__(self, tel):
        self.tel = tel

    @classmethod
    def from_email(cls, email):
        # 另一种构造方式
        return cls(tel=email)

u = User.from_email("xxx@qq.com")
```

## 二、访问控制

### 实例的私有属性

- `_attrs`：单下划线，【社区惯例，优先使用】，约定：内部成员，不建议外部使用（只是规范，外部照样可读可写）
- `__attrs`：双下划线开头，【慎用】，声明该属性为私有，实际是靠**名字改写**存成 `_类名__attrs`，外部仍可通过 `_类名__attrs` 访问（**不是真正私有**）。在类内部的方法中使用时 `self.__attrs`。防止子类同名变量意外覆盖
- `__attrs__`：前后双下划线，是魔法方法，别自己定义这种名字。

示例

```python
class User:
    def __init__(self):
        self.__pwd = "123456"

u = User()
# u.__pwd                  # 报错：AttributeError
print(u._User__pwd)        # 不报错，可以绕过拿到，不是安全私有！
```

### 实例的私有方法

- `__private_method`：双下划线开头，声明为私有方法，实际名字被改写为 `_类名__private_method`，外部仍可通过它调用（**不是真正私有**）。

## 四、魔术方法

魔术方法是 Python 内置钩子，拦截运算符、内置函数行为。

### 常用方法

| 魔术方法 | 触发时机 |
| --- | --- |
| `__init__(self, ...)` | `()` 创建实例后初始化（最常用） |
| `__new__(cls, ...)` | **真正创建实例对象**，在 `__init__` 之前，返回实例；很少重写 |
| `__del__(self)` | 对象被垃圾回收时调用，不保证执行，慎用 |
| `__str__(self)` | `str(obj)` /print (obj)，面向人看 |
| `__repr__(self)` | `repr(obj)`，开发者调试，明确对象 |
| `__add__(self, other)` | `obj + other` 加法重载 |
| `__getitem__(self, idx)` | `obj[0]` 下标取值 |
| `__setitem__(self, idx, val)` | `obj[0]=xxx` 下标赋值 |
| `__call__(self)` | `obj()` 把实例当成函数调用 |
| `__len__(self)` | `len(obj)` |
| `__eq__(self, other)` | `==` 判断相等 |

示例：

```python
class Book:
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return f"Book:{self.name}"
    def __repr__(self):
        return f"Book('{self.name}')"

b = Book("python")
print(b) # 走 __str__
```

> 区分：`__str__` 友好展示；`__repr__` 调试，理想状态 repr 字符串可以 eval 还原对象。

### `__new__` 简单示例（单例经典写法）

```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

## 五、动态特性

Python 的实例和类可以**动态增加、删除属性**

```python
class Person:
    pass

p = Person()
p.name = "小明"  # 运行时动态新增实例属性
Person.age = 18 # 动态给类加属性
del p.name      # 删除属性
```

配合 `__slots__` 可以**关闭实例动态属性**，优化内存，限制允许的属性：

```python
class Person:
    __slots__ = ("name", "age")
    def __init__(self, name):
        self.name = name
# p = Person("a")
# p.tel = 110 → 报错，不能新增不在slots里的属性
```

> slots 作用：1. 省内存；2. 禁止实例动态添加属性；**不影响类属性**。

## 六、抽象类（abc 模块）

Python 没有 abstract 关键字，靠标准库 abc 实现抽象基类，运行时校验：

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def shout(self):
        pass

# 子类必须实现所有 @abstractmethod，否则不能实例化
class Dog(Animal):
    def shout(self):
        print("wang")

# a = Animal() # 报错，抽象类不能实例化
```

> 和 Java 区别：Java 编译期报错；Python 是**实例化的时候才抛异常**。
>
> ABC 本质是用来做接口契约，不是强制必须用；鸭子类型不需要 ABC。

鸭子类型：

> **当一只鸟走起来像鸭子、游泳像鸭子、叫起来像鸭子，那它就是鸭子。**

Python 是鸭子类型语言，核心思想：**不看类型、不看继承关系，只看对象有没有需要的方法 / 属性。**

> 和 Java / C++ 的静态类型、接口契约完全不一样：
> Java：先声明实现了某个接口，编译器校验类型；
> Python：**运行时直接调用方法，有这个方法就 OK，不在乎它是什么类、继承谁。**

## 七、类型注解（typing）

给变量、函数参数和返回值“贴标签”，标明期望的类型，但它不会在【运行时】强制检查。

它主要是给 IDE 和静态类型检查工具看的，用来提前发现类型错误、增强代码提示和可读性。

```python
class User:
    def __init__(self, name: str) -> None:
        self.name: str = name
    def get_name(self) -> str:
        return self.name
```

## 八、类的底层：type

Python 中 `class` 的本质：**类是 type 的实例**

```python
# 两种写法等价
class A:
    pass

A = type("A", (), {})
```

type 三个参数：`type(类名, 父类元组, 命名空间字典)`

基于 type 自定义元类（metaclass），用来拦截类创建过程，属于进阶（框架底层用：ORM、RPC）

```python
class Meta(type):
    def __new__(cls, name, bases, attrs):
        print("创建类", name)
        return super().__new__(cls, name, bases, attrs)

class MyCls(metaclass=Meta):
    pass
```

> 元类：**类的类**，控制类怎么创建；日常业务开发几乎不用。

## 九、属性装饰器 @property（高频）

把方法伪装成属性调用，封装 getter /setter/deleter

```python
class User:
    def __init__(self, age):
        self.age = age        # 走 @age.setter → 能触发校验

    @property
    def age(self):
        # getter
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("年龄不能负数")
        self._age = value

u = User(18)
print(u.age)
u.age = 20
```

好处：对外保持 `u.age` 属性写法，内部可以加校验逻辑，兼容历史代码。
