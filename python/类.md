# 类

Python 的类是**创建对象的模板**，核心底层：**类本身也是对象（type 的实例）**。

> 一句话区分：
>
> - `class A:` → A 是类对象
> - `a = A()` → a 是实例对象

## 一、基础结构

```python
class Student:
    # 【类属性】：属于类，所有实例共享
    school = "珠海一中"

    # 构造初始化方法：实例初始化
    def __init__(self, name: str, age: int):
        # 【实例属性】self.xxx，绑定到单个实例
        self.name = name
        self.age = age

    # 【实例方法】第一个参数必须 self，代表当前实例
    def say(self):
        print(f"我是{self.name}，{self.age}岁")

# 创建实例
s1 = Student("张三", 16)
s2 = Student("李四", 17)
s1.say()
```

### 三个成员分类（重中之重）

1. **实例属性（self.xxx）**
   存在每个独立实例，实例之间互不干扰。
   `s1.name` 和 `s2.name` 互不影响。
2. **类属性（写在方法外面）**
   挂在类 `Student` 上，所有实例共享。

> ⚠️ 坑：如果 `s1.school = "二中"`，**不会修改类属性**，而是在 s1 实例上新建一个同名属性，遮蔽类属性。

```python
Student.school = "二中"  # 才是修改类属性，全部实例生效
```

3. 三种方法：实例方法、类方法、静态方法

```python
class Demo:
    # 实例方法：默认参数 self，访问实例属性
    def inst_func(self):
        print(self)

    # 类方法：@classmethod，第一个参数 cls 代表类本身
    @classmethod
    def cls_func(cls):
        print(cls)

    # 静态方法：@staticmethod，无默认参数，和类、实例无关
    @staticmethod
    def static_func():
        print("static")
```

调用方式：

```python
d = Demo()
d.inst_func()
Demo.cls_func()
Demo.static_func()
```

- 实例方法：需要实例，用来操作实例数据（最常用）
- 类方法：工厂方法、修改类属性、多构造函数场景
- 静态方法：工具函数，只是逻辑上归属这个类，不访问类 / 实例数据

> 工厂方法示例（类方法经典用法）

```python
class User:
    def __init__(self, tel):
        self.tel = tel

    @classmethod
    def from_email(cls, email):
        # 另一种构造方式
        return cls(tel=email)

u = User.from_email("xxx@qq.com")
```

## 二、访问控制

### 类的私有属性

- `__attrs`：双下划线开头，声明该属性为私有，不能在类的外部被使用或直接访问。在类内部的方法中使用时 self.__attrs。
- `__attrs__`：前后双下划线，是魔法方法，别自己定义这种名字。

### 类的私有方法

- `__private_method`：双下划线开头，声明该方法为私有方法，只能在类的内部调用 ，不能在类的外部调用。self.__private_methods。

示例

```python
class User:
    def __init__(self):
        self.__pwd = "123456"

u = User()
# u.__pwd  # AttributeError
print(u._User__pwd) # 可以绕过拿到，不是安全私有！
```

> 用途：防止子类同名变量意外覆盖，不是加密、不是权限控制。

## 四、魔术方法

魔术方法是 Python 内置钩子，拦截运算符、内置函数行为。

### 常用方法

| 魔术方法 | 触发时机 |
| --- | --- |
| `__init__(self, ...)` | `()` 创建实例后初始化（最常用） |
| `__new__(cls, ...)` | **真正创建实例对象**，在 `__init__` 之前，返回实例；很少重写 |
| `__del__(self)` | 对象被垃圾回收时调用，不保证执行，慎用 |
| `__str__(self)` | `str(obj)` /print (obj)，面向人看 |
| `__repr__(self)` | `repr(obj)`，开发者调试，明确对象 |
| `__add__(self, other)` | `obj + other` 加法重载 |
| `__getitem__(self, idx)` | `obj[0]` 下标取值 |
| `__setitem__(self, idx, val)` | `obj[0]=xxx` 下标赋值 |
| `__call__(self)` | `obj()` 把实例当成函数调用 |
| `__len__(self)` | `len(obj)` |
| `__eq__(self, other)` | `==` 判断相等 |

示例：

```python
class Book:
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return f"Book:{self.name}"
    def __repr__(self):
        return f"Book('{self.name}')"

b = Book("python")
print(b) # 走 __str__
```

> 区分：`__str__` 友好展示；`__repr__` 调试，理想状态 repr 字符串可以 eval 还原对象。

### `__new__` 简单示例（单例经典写法）

```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```
