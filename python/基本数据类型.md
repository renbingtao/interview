# 基本数据类型

Python 中的变量不需要声明。每个变量在使用前都必须赋值，变量赋值以后该变量才会被创建。

counter = 100          # 整型变量
miles   = 1000.0       # 浮点型变量
name    = "runoob"     # 字符串

## 变量赋值

Python 允许你同时为多个变量赋值。例如：
a = b = c = 1

你也可以为多个变量同时指定不同的值。例如：
a, b, c = 1, 2, "runoob"

一个变量可以通过赋值指向不同类型的对象

## 查看变量的类型

### type

可以通过 type() 函数查看变量的类型：
x = 10                 # 整数
print(type(x))         # <class 'int'>

### isinstance

此外还可以用 isinstance() 来判断：
b = '111'
print(isinstance(b, str))   # True

### isinstance 和 type 的区别

type() 不会认为子类是一种父类类型
isinstance() 会认为子类是一种父类类型，可以类比java的instance of
比如，bool 是 int 的子类，True=1，False=0，True和False可以和数字相加。则

c = True
print(type(c))                  # <class 'bool'>
print(isinstance(c, bool))      # True
print(isinstance(c, int))       # True

### issubclass

查看是否为子类
print(issubclass(bool, bool))       # True，自己也是自己的子类
print(issubclass(bool, int))        # True

py的is比较的是两个变量是否为同一个对象，可类比成java的==
py的==比较的是两个变量的值是否相等，可类比成java的equals

## 删除对象引用
可以使用 del 语句删除对象引用：
del var1[, var2[, var3[...., varN]]]    如

b = '111'
print(b)
del b
print(b)        # 报错 NameError: name 'b' is not defined

## 标准数据类型

Python3 中有 6 种【标准】数据类型，以及 bool 布尔类型（bool 是 int 的子类，有时单独列出）：

Number（数字）
String（字符串）
bool（布尔类型）
List（列表）
Tuple（元组）
Set（集合）
Dictionary（字典）

按是否可变，可以分为以下两类：

不可变数据（4 个）：Number（数字）、String（字符串）、bool（布尔）、Tuple（元组）
可变数据（3 个）：List（列表）、Dictionary（字典）、Set（集合）

## Number（数字）

Python3 支持
- int：如1，长整形。没有python2的Long
- bool：如True
- float：如1.23
- complex：复数，由实部和虚部组成，形式为a+bj，其中a是实部，b是虚部，j为虚数单位。如1.1+2.2j

整数很大时，可以用下划线分组，python会自动忽略掉。如house_price = 1_200_000

整数的最大值和计算机的内存等有关，不是固定的数值。print(整数)时，print函数内部会把整数转成数字，如果这个数字超过4300位，则会报错。但python本身是可以表示4300位的整数的（前提是内存足够）

### 数值运算

>>> 5 + 4   # 加法
9
>>> 4.3 - 2 # 减法
2.3
>>> 3 * 7   # 乘法
21
>>> 2 / 4   # 除法，得到一个浮点数
0.5
>>> 2 // 4  # 整除，得到整数部分
0
>>> 17 % 3  # 取余
2
>>> 2 ** 5  # 乘方
32

Python 3 中整数字面量不允许前导零（如 080），八进制数必须使用 0o 前缀（如 0o17），十六进制使用 0x 前缀（如 0x69），二进制使用 0b 前缀

## String（字符串）

Python 中单引号 ' 和双引号 " 使用完全相同

使用三引号(''' 或 """)可以指定一个多行字符串

```python
paragraph = """这是一个段落，
可以由多行组成"""
```

转义符 `\`

使用 r 可以让反斜杠不发生转义，如 r"this is a line with \n" 则 \n 会显示，并不是换行。r指raw

按字面意义级联字符串，如 "this " "is " "string" 会被自动转换为 this is string

字符串可以用 + 运算符连接在一起，用 * 运算符重复。如：

```python
a = '123'
print(a * 3)               # 输出123123123

print(a + '你好')         # 输出123你好
```

Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。左闭右开

```python
str = '123456789'
print(str[0:4])             # 输出1234
print(str[1])               # 输出2
print(str[7:])              # 输出89
```

字符串的切片可以加上步长参数 step，语法格式如下：str[start:end:step]。如

```python
str = '123456789'
print(str[0:5:2])           # 输出135
```

与 C 字符串不同的是，Python 字符串不能被改变。向一个索引位置赋值，比如 word[0] = 'm' 会导致错误

## bool（布尔类型）

布尔类型即 True 或 False。在 Python 中，True 和 False 都是关键字，表示布尔值。

布尔类型可以用来控制程序的流程，比如判断某个条件是否成立，或者在某个条件满足时执行某段代码。

布尔类型特点：

布尔类型只有两个值：True 和 False。
bool 是 int 的子类，因此布尔值可以被看作整数来使用，其中 True 等价于 1，False 等价于 0。

布尔类型可以和其他数据类型进行比较，比如数字、字符串等。在比较时，Python 会将 True 视为 1，False 视为 0。

布尔类型可以和逻辑运算符一起使用，包括 and、or 和 not，用来组合多个布尔表达式。

布尔类型也可以被转换成其他数据类型，比如整数、浮点数和字符串。在转换时，True 会被转换成 1，False 会被转换成 0。

可以使用 bool() 函数将其他类型的值转换为布尔值。

以下值转换为布尔值时为 False：None、False、零（0、0.0、0j）、空序列（如 ''、()、[]）和空映射（如 {}）。

其他所有值转换为布尔值时均为 True。

print(int(True))        # 1
print(int(False))       # 0

print(bool(0))          # False
print(bool(42))         # True

print(bool(''))         # False
print(bool('Python'))   # True

print(bool([]))         # False
print(bool([1, 2, 3]))  # True

## List（列表）

List（列表）是 Python 中使用最频繁的数据类型。

List 内置了有很多方法，例如 append()、pop() 等等。

列表中元素的类型可以不相同，它支持数字、字符串，甚至可以包含列表（即嵌套列表）。

列表写在方括号 [] 之间，用逗号分隔开的元素列表。

和字符串一样，列表同样可以被索引和截取，列表被截取后返回一个包含所需元素的新列表。

t = ['a','b','c','d','e']
print(t)            # 输出['a', 'b', 'c', 'd', 'e']
print(t[0])         # 输出a
print(t[1:3])       # 输出['b', 'c']
print(t * 2)        # 输出['a', 'b', 'c', 'd', 'e', 'a', 'b', 'c', 'd', 'e']

与 Python 字符串不一样的是，列表中的元素是可以改变的：
t = ['a','b','c','d','e']
t[0] = 'x'
print(t)            # 输出['x', 'b', 'c', 'd', 'e']
t[2:4] = ['y', 'z']
print(t)            # 输出['x', 'b', 'y', 'z', 'e']

同理，可以接收第三个参数，表示截取的步长
t = ['a','b','c','d','e']
print(t[1:4:2])     # 输出['b', 'd']

若第三个参数为负数，则表示逆向读取
t = ['a', 'b', 'c', 'd', 'e']
print(t[-1::-1])        # 输出['e', 'd', 'c', 'b', 'a']
