# 字符串

Python 中单引号 ' 和双引号 " 使用完全相同

使用三引号(''' 或 """)可以指定一个多行字符串

```python
paragraph = """这是一个段落，
可以由多行组成"""
```

按字面意义级联字符串

```python
s = "this " "is " "string"  # 返回this is string
```

## 运算符

字符串可以用 + 运算符连接在一起，用 * 运算符重复。如：

```python
a = '123'
print(a * 3)                # 输出123123123
print(a + '你好')           # 输出123你好
```

## 转义符 `\`

使用 r 可以让反斜杠不发生转义，如 r"this is a line with \n" 则 \n 会显示，并不是换行。r 指 raw

## 索引

Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。左闭右开

```python
str = '123456789'
print(str[0:4])             # 输出1234
print(str[1])               # 输出2
print(str[7:])              # 输出89
```

字符串的切片可以加上步长参数 step，语法格式如下：str[start:end:step]。如

```python
str = '123456789'
print(str[0:5:2])           # 输出135
```

与 C 字符串不同的是，Python 字符串不能被改变。向一个索引位置赋值，比如 word[0] = 'm' 会导致错误

## 格式化 %

旧式格式化，不推荐新项目

| 符号 | 含义 |
| --- | --- |
| %s | 字符串 str () |
| %d | 整数 |
| %f | 浮点数 |
| %.2f | 浮点数保留 2 位小数 |
| %x | 十六进制小写 |
| %% | 输出一个 % |

```python
name = "小明"
age = 18
pi = 3.1415926
s = "名字：%s，年龄：%d，圆周率：%.2f" % (name, age, pi)    # 名字：小明，年龄：18，圆周率：3.14
```

## format

语法：`"{} {}".format(值1, 值2)`

可以顺序编号、命名参数、对齐填充

```python
# 顺序
s = "{} + {} = {}".format(1, 2, 3)                          # 返回1 + 2 = 3
# 索引
s = "{0} + {1} = {2}，{0}".format(1, 2, 3)                  # 返回1 + 2 = 3，1
# 命名
s = "{name} 今年 {age}".format(name="小红", age=20)          # 返回小红 今年 20
```

`format` 和 f-string 共享同一套「格式说明符语法」

## f-string

f-string 是 Python 3.6 之后版本添加的，称之为字面量格式化字符串，是新的格式化字符串的语法。

f-string 格式化字符串以 f 开头，后面跟着字符串，字符串中的表达式用大括号 {} 包起来，它会将变量或表达式计算后的值替换进去，实例如下：

```python
name = 'Runoob'

print(f'Hello {name}!')     # 输出Hello Runoob!
```

在 Python 3.8 的版本中可以使用 = 符号来拼接运算表达式与结果：

```python
name = 'Runoob'

print(f'{name=}')       # 输出name='Runoob'
```

## 字符串内建函数

注意：字符串不可变，所有方法都**返回新字符串**，不会修改原字符串

`s` 是字符串，都是调用 `s.xxx()` 方法

Python 的字符串常用内建函数如下：

- `split()`：分割字符串为列表
- `join()`：拼接可迭代对象成字符串
- `strip()`：去除两端空白字符
- `replace()`：替换子串
- `find()`：查找子串下标，找不到返回 -1
- `index()`：查找子串下标，找不到抛异常
- `upper()` / `lower()`：大小写转换
- `startswith()` / `endswith()`：判断开头结尾
- `count()`：统计子串数量
- `isalnum()`：判断是否字母数字
