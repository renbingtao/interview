# Python3 模块

```python
import sys

print('命令行参数如下:')
for i in sys.argv:
    print(i)
```

import sys 引入 python 标准库中的 sys.py 模块；这是引入某一模块的方法。

## 模块的搜索路径

当导入一个模块时，Python 会按照以下顺序查找模块：

1. 当前目录。
2. 环境变量 PYTHONPATH 指定的目录。
3. Python 标准库目录。
4. .pth 文件中指定的目录。

搜索路径是在 Python 编译或安装的时候确定的，安装新的库应该也会修改。搜索路径被存储在 sys 模块中的 path 变量

```python
import sys

print('\n\nPython 路径为：', sys.path, '\n')
```

## from … import 语句

Python 的 from 语句让你从模块中导入一个指定的部分到当前命名空间中，语法如下：

```python
from modname import name1[, name2[, ... nameN]]
```

在解释器的当前目录里创建一个 fibo.py 的文件，代码如下：

```python
# 斐波那契(fibonacci)数列模块

def fib(n):    # 定义到 n 的斐波那契数列
    a, b = 0, 1
    while b < n:
        print(b, end=' ')
        a, b = b, a+b
    print()

def fib2(n): # 返回到 n 的斐波那契数列
    result = []
    a, b = 0, 1
    while b < n:
        result.append(b)
        a, b = b, a+b
    return result
```

要导入模块 fibo 的 fib 函数，使用如下语句：

```python
from fibo import fib, fib2

print(fib(500))
```

把一个模块的所有内容全都导入到当前的命名空间也是可行的（但是那些由单一下划线（_）开头的名字不在此例），只需使用如下声明：

```python
from modname import *
```

## 给模块起别名

使用 as 关键字为模块或函数起别名：

```python
import numpy as np  # 将 numpy 模块别名设置为 np

from math import sqrt as square_root  # 将 sqrt 函数别名设置为 square_root
```

## `__name__` 属性

一个模块被另一个程序第一次引入时，其主程序将运行。

如果我们想在模块被引入时，模块中的某一程序块不执行，我们可以用 `__name__` 属性来使该程序块仅在该模块自身运行时执行。

```python
if __name__ == '__main__':
    print('程序自身在运行')
else:
    print('我来自另一模块')
```

说明：每个模块都有一个 `__name__` 属性。

如果模块是被直接运行，`__name__` 的值为 `__main__`。

如果模块是被导入的，`__name__` 的值为模块名。

说明：`__name__` 与 `__main__` 底下是双下划线

## dir() 函数

内置的函数 dir() 可以找到模块内定义的所有名称。以一个字符串列表的形式返回:

```python
pro1 = 'abc'

def func1():
    print("abc")

print(dir())    # 输出['__builtins__', '__cached__', '__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'func1', 'pro1']
```

## 包

**模块（module）= 单个 `.py` 文件**；**包（package）= 存放多个模块的文件夹，用来组织、管理一堆相关模块**

核心本质：带 `__init__.py` 的文件夹，就是 Python 包；它是模块的容器，解决命名冲突、代码分层。

### 最简包目录示例

```text
mypackage/              # 包文件夹（包名：mypackage）
    __init__.py         # ✅ 包的标记文件（Python3.3+ 可选，但强烈建议写上）
    module_a.py         # 模块 mypackage.module_a
    module_b.py         # 模块 mypackage.module_b
    subpkg/             # 子包（嵌套包）
        __init__.py
        module_c.py
```

### `__init__.py` 作用

1. 告诉 Python：**这个文件夹是包，不是普通文件夹**
2. 导入包的时候，会**自动执行这个文件里的代码**

### 导入语法

假设结构：`mypackage.module_a`，里面有函数 `hello()`

```python
# 1. 完整导入模块（推荐，可读性最好）
import mypackage.module_a
mypackage.module_a.hello()

# 2. 导入模块并起别名
import mypackage.module_a as ma
ma.hello()

# 3. 从包/模块里导入指定对象
from mypackage.module_a import hello
hello()

# 4. 从包导入模块（子包同理）
from mypackage import module_a
module_a.hello()
```

### 相对导入

```python
# 在 subpkg/module_c.py 里面，想导入上层的 module_a
from .. import module_a       # .. 代表上一级包
from . import module_c        # . 代表当前包
```

- `.` = 当前包
- `..` = 父包
- `...` = 祖父包

### 从一个包中导入*

**`from pkg import *` 不是自动导入包里面所有 py 文件，它受 `__all__` 控制**，把这个变量中的所有名字作为包内容导入

修改 `mypackage/__init__.py`

```python
# mypackage/__init__.py
from . import module_a
from . import module_b
from . import subpkg

__all__ = ["module_a", "module_b", "subpkg"]
```

外部脚本：

```python
from mypackage import *

module_a.func_a()
module_b.func_b()
subpkg.module_c.func_c()
```

❌ 错误认知：

> `from mypackage import *` 自动把 module_a、module_b、subpkg 全部导进来

✅ 真相：

**如果 `mypackage/__init__.py` 是空的，哪怕目录里有这么多文件，`from mypackage import *` 什么都拿不到！**
它不会自动遍历文件夹加载 py，必须你在 `__init__.py` 显式导入。
