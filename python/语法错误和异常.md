# Python3 语法错误和异常

## 语法错误

代码写错，解释器**根本不执行**，解析阶段直接报错，不属于异常。 例子：

```python
if True
    print(1)
```

常见：少冒号、括号不匹配、缩进错误、关键字拼写错误。

> 缩进错误 `IndentationError` 是 SyntaxError 的子类，也属于语法错误。

## 异常

语法没问题，运行的时候才出问题，可以捕获、处理。

### 异常体系（继承树）

```text
BaseException
 ├─ Exception                # 绝大多数业务异常的父类（日常捕获这个或者它子类）
 │   ├─ ArithmeticError      # 计算类错误
 │   │   ├─ ZeroDivisionError 除0
 │   │   └─ OverflowError 数值溢出
 │   ├─ LookupError          # 索引/键查找错误
 │   │   ├─ IndexError 列表索引越界
 │   │   └─ KeyError 字典key不存在
 │   ├─ AttributeError       # 对象没有这个属性/方法
 │   ├─ NameError            # 变量未定义
 │   ├─ TypeError            # 类型不对，比如 str + int
 │   ├─ ValueError           # 值合法类型，但内容不对：int("abc")
 │   ├─ FileNotFoundError    # 文件不存在（OSError子类）
 │   ├─ PermissionError      # 权限不足（OSError子类）
 │   └─ ...其他
 ├─ GeneratorExit            # 生成器退出（不要捕获）
 ├─ SystemExit               # sys.exit() 抛出，不要随便捕获
 └─ KeyboardInterrupt        # Ctrl+C 中断程序
```

### try-except 基础语法

完整结构：`try → except → else → finally`

try没有抛异常时，会执行else里的代码

如果一个异常在 try 子句里（或者在 except 和 else 子句里）被抛出，而又没有任何的 except 把它截住，那么这个异常会在 finally 子句执行后被抛出。

```python
try:
    # 【监控区】可能抛异常的代码
    a = 1 / 0
except ZeroDivisionError as e:
    # 捕获指定异常，e 是异常实例
    print("除零错误：", e)
except (IndexError, KeyError) as e:
    # 同时捕获多种异常
    print("索引或键错误", e)
except Exception as e:
    # 兜底，捕获上面没命中的普通异常，写在最后
    # 不能把 `except Exception` 写在前面，会拦截后面所有子类异常。
    print("其他异常", type(e), e)
else:
    # ✅ 只有 try 里面【没有抛出任何异常】才执行！
    print("正常跑完，没有报错")
finally:
    # ✅ 无论是否异常、是否return，一定会执行！适合释放资源（关闭文件、连接）
    # finally 里尽量不要写 return /raise，会覆盖上层返回值，坑很多
    print("finally 永远执行")
```

### 主动抛出异常 raise

可以手动抛出内置异常，或者自定义异常

```python
# 基础
raise ValueError("年龄不能是负数")

# 捕获之后，原样向上抛出（不吞异常，只做日志）
try:
    1/0
except ZeroDivisionError as e:
    print("记录日志")
    raise   # 不带参数，重新抛出原来的异常
```

### 自定义异常

继承 `Exception`（不要继承 BaseException），用于业务分层识别

```python
class BizError(Exception):
    """业务异常基类"""
    pass

class BalanceNotEnoughError(BizError):
    """余额不足"""
    pass

def pay(balance):
    if balance < 100:
        raise BalanceNotEnoughError(f"余额{balance}不足")

try:
    pay(50)
except BalanceNotEnoughError as e:
    print(e)
```

### 异常链（Python3 特性）

1. 隐式链：异常 A 处理过程中抛出异常 B，自动记录 **cause** / **context**

```python
try:
    open("xxx.txt")
except FileNotFoundError as e:
    raise RuntimeError("读取配置失败")
```

2. 显式使用 `raise ... from e`（明确关联根因）

```python
try:
    open("xxx.txt")
except FileNotFoundError as e:
    raise RuntimeError("读取配置失败") from e
```

`from None` 可以**切断异常链**，不展示原始异常（对外屏蔽底层细节）

```python
raise RuntimeError("读取配置失败") from None
```

### traceback 模块：打印完整堆栈

捕获异常后，默认 `print(e)` 只有简短信息；想要完整报错栈，用 traceback

```python
import traceback
try:
    1/0
except Exception:
    traceback.print_exc()  # 控制台打印完整堆栈
    # 或者拿到字符串写日志
    err_str = traceback.format_exc()
```

### assert 断言

`assert 条件, 提示`，条件为 False 抛出 `AssertionError`

```python
age = -1
assert age > 0, "age必须大于0"
```

### 异常相关内置函数：sys.exc_info ()

在 except 块内获取当前异常三元组 `(exc_type, exc_value, traceback_obj)`

```python
import sys
try:
    1/0
except Exception:
    tp, val, tb = sys.exc_info()
```
