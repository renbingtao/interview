# Python3 语法错误和异常

## 语法错误

代码写错，解释器**根本不执行**，解析阶段直接报错，不属于异常。 例子：

```python
if True
    print(1)
```

常见：少冒号、括号不匹配、缩进错误、关键字拼写错误。

> 缩进错误 `IndentationError` 是 SyntaxError 的子类，也属于语法错误。

## 异常

语法没问题，运行的时候才出问题，可以捕获、处理。

### 异常体系（继承树）

```text
BaseException
 ├─ Exception                # 绝大多数业务异常的父类（日常捕获这个或者它子类）
 │   ├─ ArithmeticError      # 计算类错误
 │   │   ├─ ZeroDivisionError 除0
 │   │   └─ OverflowError 数值溢出
 │   ├─ LookupError          # 索引/键查找错误
 │   │   ├─ IndexError 列表索引越界
 │   │   └─ KeyError 字典key不存在
 │   ├─ AttributeError       # 对象没有这个属性/方法
 │   ├─ NameError            # 变量未定义
 │   ├─ TypeError            # 类型不对，比如 str + int
 │   ├─ ValueError           # 值合法类型，但内容不对：int("abc")
 │   ├─ FileNotFoundError    # 文件不存在（OSError子类）
 │   ├─ PermissionError      # 权限不足（OSError子类）
 │   └─ ...其他
 ├─ GeneratorExit            # 生成器退出（不要捕获）
 ├─ SystemExit               # sys.exit() 抛出，不要随便捕获
 └─ KeyboardInterrupt        # Ctrl+C 中断程序
```

### try-except 基础语法

完整结构：`try → except → else → finally`

try没有抛异常时，会执行else里的代码

```python
try:
    # 【监控区】可能抛异常的代码
    a = 1 / 0
except ZeroDivisionError as e:
    # 捕获指定异常，e 是异常实例
    print("除零错误：", e)
except (IndexError, KeyError) as e:
    # 同时捕获多种异常
    print("索引或键错误", e)
except Exception as e:
    # 兜底，捕获上面没命中的普通异常，写在最后
    # 不能把 `except Exception` 写在前面，会拦截后面所有子类异常。
    print("其他异常", type(e), e)
else:
    # ✅ 只有 try 里面【没有抛出任何异常】才执行！
    print("正常跑完，没有报错")
finally:
    # ✅ 无论是否异常、是否return，一定会执行！适合释放资源（关闭文件、连接）
    # finally 里尽量不要写 return /raise，会覆盖上层返回值，坑很多
    print("finally 永远执行")
```
