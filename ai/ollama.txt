
============================== 模型安装 ==============================

ollama下载地址
https://ollama.com/download

windows斑斑
exe直接安装

linux版本
curl -fsSL https://ollama.com/install.sh | sh

更新模型下载路径
Settings -> Model location

模型搜索及下载地址
https://ollama.com/search

============================== 模型运行 ==============================

以qwen2.5-coder为例
https://ollama.com/library/qwen2.5-coder
选择qwen2.5-coder:14b模型

cd C:\Users\user\AppData\Local\Programs\Ollama
./ollama run qwen2.5-coder:14b

============================== 提示工程 ==============================

编写Modelfile文件，示例如下


FROM qwen2.5-coder:14b
SYSTEM """
系统提示词xxx
"""


创建自定义大模型
./ollama create my-model -f .\Modelfile

删除自定义大模型
./ollama rm my-model

============================== 常用命令 ==============================

# 执行一次prompt
ollama run qwen3.6-35b-32k "你好"

# 查看当前加载到显存里的模型
ollama ps

# 卸载指定模型，立刻释放GPU显存，磁盘模型文件不会删除
ollama stop qwen3.6-35b-32k
